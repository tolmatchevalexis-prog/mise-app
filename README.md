# mise-app
M.I.S.E – Un système de jeu de rôle sans dés.
M.I.S.E. — Prototype d'application de personnages
Prototype mobile en noir et blanc, fidèle aux croquis d'interface.
Pages
Accueil : cartouches avec uniquement le nom des personnages, bouton de création.
Création / modification : nom, trois attributs de 1 à 4 sous forme de cercles, compétences, historique, validation.
Compétences : nom, quatre niveaux (Novice +1, Confirmé +2, Expert +3, Maître +5), description facultative.
Fiche : consultation et retour vers l'édition.
Tester
Ouvrir index.html dans un navigateur. Aucune installation et aucune dépendance nécessaire.
Les personnages sont conservés dans le stockage local du navigateur (localStorage). Ce prototype n'a pas encore de synchronisation, d'export ni de mode hors-ligne PWA. La suppression des données du navigateur peut donc effacer les personnages.
Pour publier sur GitHub Pages : placer index.html à la racine du dépôt, puis activer Settings → Pages → Deploy from a branch → main / root.
